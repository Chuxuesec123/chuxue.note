# 从零到 SRC：Web 漏洞挖掘实战

这是一套**从零开始、动手为主**的 Web 安全入门系列。目标不是把你变成"payload 复读机"，而是让你能独立完成：

```text
读规则 → 收集资产 → 找入口 → 验证漏洞 → 控制影响 → 写报告
```

全系列 13 篇主线 + 1 篇速查手册，建议按顺序读；每篇末尾都有自检清单和下一篇链接。

> **法律边界：** 所有技术只用于**自己搭建的靶场**或**明确书面授权的 SRC/众测目标**。未授权测试、拖库、写 webshell、反弹 shell、破坏业务，都可能触犯法律。第 0 篇会把红线讲清楚。

## 三、每篇的结构

```text
原理 → 有漏洞的代码 → 本地复现 → 绕过手法 → 防御写法 → SRC 测试建议 → 自检清单
```

每篇都尽量做到：

- 有可运行的本地靶场/代码；
- 有真实的请求/响应/payload；
- 有"为什么这样能成"的解释；
- 有"怎么修"的代码；
- 有"SRC 里只证明、不破坏"的边界提醒。


## 五、最后

学安全最容易走偏的两条路：

1. **只背 payload**：换个环境就不会了；
2. **只追求 getshell**：忽略业务影响和报告，挖到了也交不出去。

这套笔记想让你走第三条路：**理解原理、控制边界、能复现、能写清楚**。
